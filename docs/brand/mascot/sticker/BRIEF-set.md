The attached image is the approved design of Axiko — keep EXACTLY this character and style in
every image: sticker-pack illustration, thick soft dark-violet outline `#3B2F8F`, flat fills, a

short tail with a pink fin edge. Same head shape, proportions and line weight as the reference.
No text, letters or logos in any image.

Use your image generation tool to create FIVE separate images in this order. Do not write code and
do not move or save files yourself. In your final message list them in order with the full path of
each generated PNG.
