# Аксико-стикер: заметки

Утверждённый стиль — вариант 5 из [листа вариантов](../variants/contact-sheet.webp). Всё здесь
нарисовано Codex CLI 0.162.1 16.11.2026 с этим вариантом как образцом и перенесено из
`~/.codex/generated_images` (сам Codex в папку проекта писать не смог).

## Что в приложении

Маскот приложения — векторные позы в `app/src/main/assets/factory/ui/mascot/`. Они собраны из
картинок этой папки, как устроено и как пересобрать — в [brand.md](../../../brand.md).

| Здесь | Что это |
|---|---|
| `poses/<поза>.webp` | Исходники поз: плоские цвета, фон `#E9E2DC` (задания: [первый набор](BRIEF-poses.md), [второй](BRIEF-poses-2.md), [слои для кнопки чата](BRIEF-peek.md)). `hello` — сам утверждённый образец |
| `poses/<поза>.json` | Описание для трассировки: где кайма хвоста, рот и табличка, какие у позы дополнительные цвета; `source` и `crop` — взять часть другой картинки (лапка из `peek-paws.webp`) |
| `poses-sheet.png` | Все позы уже в векторе, на тёмном и светлом — лист проверки (`scripts/brand/build.py`) |
| `in-app/*.png` | Экраны приложения с маскотом, снятые в браузере (`scripts/brand/preview.py`), и иконка |
| `svg/compare.png`, `svg/themes.png` | Первая проверка векторизации: сравнение с оригиналом, перекраска, состояния |

Расхождение вектора с картинками — 0,16–0,42% пикселей, только на сглаженных краях.

## Первые наброски (в приложение не вошли)

`model-sheet.webp`, `expressions.webp`, `onboarding-*.webp`, `app-icon.webp`, `themes/` — первый растровый
набор в стиле стикера ([BRIEF-set.md](BRIEF-set.md), [BRIEF-themes.md](BRIEF-themes.md)). По ним
выбирали стиль и окрасы тем; позы для приложения потом нарисованы заново, по одной и в полном размере.
