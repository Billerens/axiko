# Проверка web-игр: окно хаба, управление и толкования

Дата: 15 ноября 2026. Проверены локальные исходники Assi и assi-store.
Проверки ниже выполнены в Node.js 22 и локальном Chromium через CDP; команды запускались
из PowerShell 7. Телефон, пользовательский ADB и Gradle в этих проверках не использовались.

## Изменения

| Область | Результат |
| --- | --- |
| Общий запуск игр | Web-мост обозначает `platform: 'web'`; `Game.start()` не вызывает `stage(true)` для браузера. Игра остаётся в рабочей области хаба. Разворачивание доступно по кнопке «На весь экран». Native-поведение сохраняется. |
| `wave-survival` | Название «Последний рубеж». ID игры, сохранения и баланс прежние. На арене вместо круга отображается пиксельный боец: два кешированных кадра ходьбы, поворот по направлению движения, палитра выбранного героя. |
| Управление волнами | WASD и стрелки; P/Esc ставят на паузу. Физический `KeyboardEvent.code` поддерживает русскую раскладку. При потере фокуса и открытии карточек клавиши сбрасываются; диагональный вектор нормируется. Джойстик сохранён. |
| `word-weaver` | Толкования в альбоме открыты сразу. Последнее верное слово и его определение остаются отдельной карточкой, включая ошибку при следующем вводе. Если определение ещё готовится, карточка обновляется после ответа модели. |
| Типография | Существующее улучшение теперь выводит недавние слова альбома также на узком главном экране. Формат состояния и числовой баланс не менялись. |

Браузерные проверки используют реальный общий движок Игротеки, временную рабочую папку,
локальный HTTP-мост и синтетическое состояние. Для толкований подставлен локальный ответ;
внешняя модель и качество её определений здесь не проверяются. PNG-снимки создаются во
временной папке; путь к каждому снимку выводится в результате browser-теста. Узкий экран
с новым игроком и карточкой определения просмотрен визуально.

Команды из корня Assi:

```powershell
node --test scripts/web/transport.test.js
```

Команды из корня assi-store:

```powershell
node wave-survival/tests/browser.test.js
node word-weaver/tests/browser.test.js
node word-weaver/tests/rules.test.js
node word-weaver/tests/lint.test.js
node wave-survival/tests/lint.test.js
node wave-survival/tests/world.test.js
```

## Файлы и распространение

Общий web-фикс находится в заводском слое Assi:

- `app/src/main/assets/factory/ui/desk/client.js`;
- `app/src/main/assets/factory/ui/desk/index.html`;
- `app/src/main/assets/factory/modules/games/engine/game.js`.

Игры поставляются отдельными папками assi-store; собственных заводских копий этих двух игр
в APK нет. У магазина сейчас нет release-version, общего публикуемого каталога и автоматического
обновлятора: `install.ps1` устанавливает файлы по `store.json.target`. Игротека сама перечисляет
установленные `game.json`. Название обновлено в `wave-survival/store.json` и `game.json`;
`saveVersion` и `engine` не повышались, поскольку формат сохранений и протокол не менялись.

`Workspace.installFactory()` сравнивает содержимое заводских файлов по хешам. Изменённый
пользователем активный файл сохраняется, поэтому его обновление требует отдельного переноса
нужной правки с предварительным снимком. Публикация, коммит и установка на телефон в рамках
этого отчёта не выполнялись.
