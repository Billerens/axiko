## Обои дня

Сохранённая диагностическая ошибка: `Cannot find function intValue.`. В Assi у Rhino задано
`WrapFactory.isJavaPrimitiveWrap = false`: `Integer.valueOf()` возвращает в JavaScript обычное
число, у которого нет `.intValue()`. Выбор и кадрирование картинки проходили, установка падала.

В `wallpapers/android.js` флаги передаются через `Number(which)`. Для обычной установки явно
выбрана сигнатура `setBitmap(Bitmap, Rect, boolean, int)`, чтобы новые перегрузки Android не
создавали неоднозначность при передаче `null` вместо кадрирования. Исправлены оба места с
`.intValue()`, включая путь нескольких кадров.

Проверки:

- `wallpapers/tests/android.test.js` исполняет настоящий адаптер с числовыми Java-результатами,
  проверяет домашний экран, блокировку, специальный флаг и освобождение bitmap при отказе.
- В настоящем Rhino эмулятора подтверждено `typeof Integer.valueOf(1) === 'number'`.
- Синтетическая PNG 128×128 установлена через исправленный адаптер: `allowed:true`,
  `ok:true`, `mode:single`, экраны `inner`, `cover`, `lock`. Временный файл удалён.
- Особые Samsung-флаги и разные кадры Fold на физическом телефоне не проверялись.

## Сериал на ночь

`renderNew()` передавал `null` непосредственно в стандартный `Element.replaceChildren()`
для отсутствующего поля своего жанра и кнопки отмены. DOM превращает такой аргумент в текст
`null`; фильтрация необязательных детей внутри `ui.h()` здесь не участвует.

В `bedtime-series/ui/index.html` необязательные элементы фильтруются перед `replaceChildren`.
`bedtime-series/tests/ui.test.js` исполняет настоящий скрипт страницы и проверяет начальную
форму, свой жанр и завершённый сезон с семантикой DOM, преобразующей `null` в строку.

Настоящая страница на эмуляторе проверена в двух состояниях:

- Без зависимости `voice-adventure`: `loaded:true`, `errors:[]`, корректное сообщение об отсутствии
  голосового движка.
- После копирования зависимости из магазина: `loaded:true`, `errors:[]`, `engine:true`.
  Начальная форма с кнопкой «Начать сезон» видна; переключение на свой жанр показывает поле
  «О чём сезон». Проверка текстовых узлов: `literalNullNodes:0`, `visibleNull:false`; в форме
  12 кнопок. В конце возвращён исходный жанр.

Сезоны не создавались, генерация и обращения к LLM не запускались.

## Траты

У сохранённой очереди был формат Samsung Wallet: «название карты. продавец сумма BYN», без
слова «Оплачено». Старое правило Wallet требовало это слово, а общий разбор искал продавца
после суммы и признак операции. Поэтому сообщения попадали в очередь, а операций не было.

Добавлено ограниченное правило `samsung-wallet-receipt`: только известные пакеты Samsung
Wallet, узнаваемый заголовок карты, одна сумма, продавец перед ней. Уведомления о балансе,
несколько сумм, реклама и явно другой тип операции не принимаются этим правилом. В список
кошельков добавлен пакет `com.samsung.android.wallet*`.

После обновления версии правил `main.js` один раз запускает фоновый повтор сохранённой очереди
без отправки текстов модели. Очередь удаляется только после записи операции. Сбой записи
оставляет сообщение для повтора; уже сохранённая операция распознаётся по хешу, времени и
отправителю, чтобы прерывание между записью и удалением очереди не создало дубль.

Проверки:

- Все 9 проблемных сообщений из сохранённого бэкапа разобраны новым правилом локально;
  выводились только агрегаты, без текстов, сумм, продавцов или номеров карт.
- `spending/tests/wallet.test.js`: вымышленные чеки, неподходящий отправитель, несколько сумм,
  возврат, баланс, реклама, обработка старой очереди при старте, повторный запуск и сбой записи.
- Настоящий Rhino/SQLite эмулятора: синтетическое уведомление → `status:ok`, валюта BYN;
  повтор того же ключа → `skip`; отдельное сообщение в очереди → `{ok:1,still:0,failed:0}`,
  очередь очищена. Созданные тестом операции удалены по их ID, исходные настройки восстановлены.
- Модель и уведомления в Android smoke были выключены; личные данные на эмулятор не переносились.

Валюта бюджета по умолчанию остаётся RUB. Для бюджета в белорусских рублях выбирают BYN в
настройках. Операция в другой валюте сохраняется в исходной валюте; без доступного курса она
помечается как ожидающая пересчёта, а не прибавляется к бюджету с неверным курсом.
