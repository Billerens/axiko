# Шляпа

> Игра для компании по мотивам народной «Шляпы»: объясняешь слово, не называя его, а телефон сам слышит, когда его угадали, и засчитывает — кнопки нажимать не нужно.

Название модуля — «Шляпа»: это народная игра, свободная от чьих-либо прав. Слово Alias — торговая марка настольной игры, его в интерфейсе не используем, правила и карточки — свои.

## Зачем

- Собрались вшестером, бумаги и ручек нет: телефон за 20 секунд выдаёт колоду из 60 слов под компанию («кино и сериалы», средняя сложность) и ведёт счёт.
- Объясняющий держит сложенный телефон и говорит; как только кто-то крикнул «Холодильник!», телефон вибрирует и показывает следующее слово. Руки свободны для жестов.
- Классика «Шляпы»: каждый вписывает свои слова втайне от остальных — по кругу передавая телефон.
- Три раунда с одной колодой: объяснить словами, показать жестами, одним словом. Во втором раунде микрофон слушает угадывающих так же.
- Слова не повторяются от вечера к вечеру: модуль помнит сыгранные.
- Итоги вечера: лучший объясняющий, самое быстрое слово (2,1 с), самое трудное слово.

## Что видит владелец

**Подготовка** (раскрытый Fold, кит, одна прокручиваемая страница в две колонки):
- слева — игроки: имена (ввод или голос), режим «Пары» (классика: пары меняются) или «Команды» (2–4 команды), раскладка по командам перетаскиванием;
- справа — колода: тема (чипы: «общее», «кино», «еда», «природа», «профессии», «IT», «история», «своя тема» — поле ввода), сложность 1–5, слов на игрока, «свои слова игроков» (вкл/выкл), кнопка «Собрать колоду». Пока модель пишет — `spinner` и надпись «Модель подбирает 60 слов, обычно 15–30 секунд». Колоду можно собрать заранее, пока есть сеть.
- внизу — «Время хода», «Раунды», «Автозачёт голосом» (переключатель), «Начать».

**Ввод своих слов** — сложенный телефон по кругу: «Ход Маши: впишите 5 слов, остальные не смотрят». Поле, кнопка «Готово» прячет слова. Повторы в колоде подсвечиваются только владельцу хода («это слово уже есть, выберите другое»).

**Ход** — внешний экран (сложенный телефон в руке объясняющего), `assi.stage(true)`:
- крупно слово (до 48 px, переносы по слогам запрещены, длинные — меньше);
- таймер полосой и числом; последние 5 секунд — тиканье (WebAudio) и вибрация на каждой секунде;
- индикатор микрофона (уровень из события `speech`) — видно, что телефон слышит;
- кнопки внизу экрана, по 64 px высотой: «Пропуск», «Угадали» (ручной зачёт, если голос не сработал), «Отмена» (вернуть последний зачёт, 5 с после него);
- при автозачёте: короткая вибрация 40 мс, слово уходит вверх, под ним мелко — что услышано («холодильником»), следующее слово.

**Между ходами** — раскрытый экран для всех: таблица очков, кто объясняет следующим и кому, «Передайте телефон Пете», кнопка «Начать ход» (отсчёт 3-2-1). Список слов хода с отметками: угадано (кем — если пары), пропущено, отменено; спорные можно исправить касанием.

**Итоги** — раскрытый экран: места, «Лучший объясняющий» (слов в минуту), «Самое быстрое слово», «Не угадали ни разу» (останется в следующей колоде, если включено).

Голос вне игры: «Axiko, давай в шляпу, нас шестеро, тема — кино» — агент открывает экран подготовки с заполненными полями.

**Настройки** (`data/hat/settings.json`):

| Настройка | По умолчанию |
|---|---|
| Время хода, с | 60 |
| Раунды | 3 (словами, жестами, одним словом); 1 — только словами |
| Слов на игрока в колоде | 8 |
| Сложность | 3 из 5 |
| Штраф за пропуск | 0 (вариант −1) |
| Последнее слово: время на угадывание после конца хода, с | 3 |
| Автозачёт голосом | да |
| Длина куска распознавания, с | 4 |
| Окно «Отмена», с | 5 |
| Не повторять слова, последних | 3000 |
| Допускать формы слова (падежи, число) | да |
| Допускать опечатки распознавания: длина ≥ 6 — 1 буква, ≥ 10 — 2 | да |

## Как устроено

### Правила (наши)

- **Пары** (по умолчанию для чётного числа игроков 4–12): игроки по кругу, в первом круге объясняет игрок `i` игроку `i + N/2`; каждый следующий круг пары сдвигаются, чтобы все объяснили всем. Очко получают оба в паре. Для нечётного N — режим «Команды».
- **Команды**: 2–4 команды по 2+ человека; объясняющий внутри команды меняется по кругу; угадывает вся команда; очко — команде.
- **Ход**: время хода, слова идут по одному из «шляпы» (перемешанная колода). Угадано — +1, следующее слово. Пропуск — слово возвращается в шляпу, штраф по настройке.
- **Нельзя** называть само слово и однокоренные, переводить на другой язык, показывать буквы. Нарушение — кнопка «Отмена» у слова: очко снимается, слово возвращается в шляпу.
- **Последнее слово**: если ход кончился, а слово объяснялось, его можно угадать за 3 с.
- **Раунды**: колода общая на три раунда; раунд кончается, когда шляпа пуста. 2-й раунд — только жесты (микрофон слушает угадывающих), 3-й — одно слово объяснения.
- Своё отличие от народной игры — «**Горячее слово**» (вкл/выкл): раз в раунд в шляпе одно слово стоит 3 очка; объясняющий видит отметку `star`, остальные — нет.

### Колода

Роль `hat.words` (`module.json` → `models`). Запрос раз на колоду. Промпт: тема, сложность, число слов, язык — русский, «только нарицательные существительные или устойчивые словосочетания до двух слов, без имён собственных (кроме темы "кино"), без грубых слов (если не включено)», список из 200 последних сыгранных слов — «не повторяй». Ответ JSON:

```json
{ "words": [
  { "word": "холодильник", "forms": ["холодильника", "холодильнику", "холодильником", "холодильнике", "холодильники", "холодильников", "холодильникам", "холодильниками", "холодильниках"],
    "roots": ["холод"], "difficulty": 2 },
  { "word": "железная дорога", "forms": ["железной дороги", "железную дорогу", "железной дорогой", "железные дороги"], "roots": ["желез", "дорог"], "difficulty": 3 } ] }
```

Уровни сложности в промпте с примерами: 1 — «кошка, стол, мяч»; 2 — «зонтик, сугроб, повар»; 3 — «бухгалтер, водопад, сквозняк»; 4 — «ностальгия, монополия, акведук»; 5 — «прецедент, апатия, энтропия».

Проверка ответа в движке: убрать дубли (после нормализации), слова из истории, слова длиннее 24 букв, слова с латиницей и цифрами; не хватает — дозапрос на недостающее. Колода сохраняется — играть можно без сети. Без модели (нет сети и не собрано заранее) — запасной словарь `modules/hat/words.json` (около 1500 слов по уровням, составляется моделью один раз при установке модуля и проверяется глазами владельца).

Свои слова игроков: формы для них — тем же запросом модели в момент «Готово» (если есть сеть), иначе — правило окончаний (ниже).

### Распознавание и зачёт

Распознавание — GigaAM на телефоне (без сети, русский). Цель — заметить слово за 1–2 с после того, как его крикнули.

**Сейчас (без правки оболочки).** Экран крутит цикл `await assi.native('speech.listen', 4)` всё время хода. Как работает `speech.listen` в `Stt.kt`: открывает микрофон, режет речь детектором Silero VAD, заканчивает после 1 с тишины, через `maxSeconds` или через 8 с без речи, затем распознаёт куски. В шумной комнате тишины нет — кусок заканчивается по пределу (4 с, настройка), значит задержка зачёта — 2–5 с плюс время распознавания и перезапуск микрофона между вызовами (слова на стыке кусков могут потеряться). Для первой версии терпимо — проверить на телефоне.

Перед игрой модуль выключает отклик на имя (`wake.status` → запомнить, `wake.set(false)`), после игры — возвращает: два слушателя микрофона одновременно не работают. Звуки игры (тиканье) на время распознавания — тише или отключены (настройка), чтобы не мешать.

**Как надо (правка оболочки).** Непрерывный режим распознавания:
- `speech.stream.start({ silence: 0.3, maxPhrase: 5 })` — микрофон открыт до `speech.stream.stop`; каждый кусок речи, отрезанный VAD по короткой паузе 0,3 с или по пределу 5 с, распознаётся в фоне и приходит на экран событием `speech.phrase` `{ text, from, to }`. Источник звука — `VOICE_RECOGNITION` с `NoiseSuppressor`, как в `Live.kt`.
- Ещё быстрее — **поиск ключевых слов**: в оболочке уже есть потоковая модель `KeywordSpotter` (`Wake.kt`, модель `kws-ru`, 23 МБ), которая караулит имя ассистента. Ей можно передать формы текущего слова: `speech.spot.start(['холодильник', 'холодильника', …])` → событие `speech.spotted` через сотни миллисекунд, затем подтверждение распознаванием GigaAM этого же куска. Насколько хорошо KWS ловит произвольные слова (он настроен на имя) — проверить на телефоне.

**Сравнение услышанного со словом** (`modules/hat/match.js`, одна функция `matches(heard, card)` → `{ ok, token, how }`):
1. Нормализация: нижний регистр, `ё → е`, убрать знаки препинания, дефисы → пробел, числа цифрами → словами (для слов-чисел).
2. Совпадение с `word` или любой из `forms` — `how: 'exact'`.
3. Правило окончаний (если формы не пришли): отрезать окончание из списка (`ами, ями, ого, его, ому, ему, ой, ей, ом, ем, ам, ям, ах, ях, ов, ев, а, я, ы, и, у, ю, е, о`), сравнить основы; основа не короче 4 букв и не короче длины слова минус 3 — `how: 'stem'`.
4. Похожесть для ошибок распознавания: расстояние Левенштейна ≤ 1 при длине ≥ 6, ≤ 2 при длине ≥ 10 — `how: 'fuzzy'`; для слов короче 6 — только точно и по формам.
5. Словосочетание: все части найдены в услышанном в пределах 4 слов подряд в любой форме.
6. Однословная колода против случайных совпадений: короткие слова (≤ 3 букв: «кит», «сок») засчитываются только как отдельное слово, не как часть другого.

**Кто сказал?** Распознавание не отличает объясняющего от угадывающих. Если объясняющий нарушил правило и назвал слово — телефон засчитает. Для этого «Отмена» на 5 с крупная и всегда под пальцем. Честно пишем об этом на экране правил.

**Шум.** Музыка и разговоры соседей: VAD видит «речь» почти всегда, поэтому куски режутся по пределу; распознавание шумной речи хуже. Советы на экране перед игрой: приглушить музыку, держать телефон микрофоном к угадывающим (у Fold5 микрофоны сверху и снизу корпуса — проверить, какой используется в сложенном виде). Ложный зачёт от чужого разговора маловероятен (слово должно совпасть), но возможен — «Отмена».

**Цена.** Распознавание — на телефоне, бесплатно; это нагрузка на процессор весь ход (непрерывная работа VAD и GigaAM) — за вечер в 2 часа ожидаемо 10–20% батареи, проверить. Модель — один запрос на колоду (60–120 слов с формами — 3–8 тысяч токенов ответа); можно назначить роли локальную модель, но формы слов у маленьких моделей хуже — тогда спасает правило окончаний.

## Данные

`data/hat.db`:
- `decks`: `id`, `created`, `theme`, `difficulty`, `cards` (JSON: `word`, `forms`, `roots`, `difficulty`, `owner` — чьё слово, если своё).
- `games`: `id`, `started`, `ended`, `mode` (`pairs`/`teams`), `players` (JSON), `teams` (JSON), `settings` (JSON — снимок), `deck_id`, `scores` (JSON).

- `word_history`: `word`, `played_at`, `guessed` (0/1) — для «не повторять» и «трудных слов»; хранить последние 3000 (настройка).

Хранение: игры — всегда (маленькие), колоды — 90 дней, если не отмечены «сохранить». В общую базу — одна запись на вечер: `{ kind: 'event', title: 'Шляпа', tags: ['игра', 'компания'], data: { players: 6, words: 58, winner: 'Маша и Петя' }, source: 'hat' }` — для [Ачивок](achievements.md) и [Сериала на ночь](bedtime-series.md) («вчера вы играли в шляпу»). Имена гостей в базу не пишутся, если владелец выключил это в настройках.

## Что нужно от оболочки

Есть сейчас: `speech.listen(maxSeconds)`, событие `speech` с уровнем, `wake.status`/`wake.set`, `ai.ask` с ролью и `json`, `assi.db`, `assi.vibrate`, `assi.stage(true)` на экране, WebAudio в WebView.

Нужна правка оболочки (для хорошей версии):
- **`speech.stream.start/stop`** — непрерывное распознавание кусками с событием `speech.phrase`. Почти всё уже есть в `Stt.kt` (`vad`, `decode`) и `Live.kt` (непрерывный микрофон, шумоподавление): новая операция в `Native.kt` и цикл без выхода после первой фразы.
- **`speech.spot.start(words)`** — по желанию: `KeywordSpotter` из `Wake.kt` с переданным списком слов.

Проверить на телефоне: задержку зачёта с циклом `speech.listen(4)`; время распознавания куска 4 с GigaAM на Fold5; какой микрофон работает в сложенном виде; можно ли держать `assi.stage(true)` на внешнем экране.

## Этапы

1. **Ручная шляпа.** Игроки, пары, колода из запасного словаря, ход с кнопками «Угадали»/«Пропуск», таймер, счёт. Без голоса.
2. **Колода моделью.** Роль `hat.words`, темы, сложность, формы, история «не повторять».
3. **Сравнение слов.** `match.js` с тестами в `checks.js` (по 30 примеров на каждое правило, включая «железной дорогой», «кит» внутри «китайский» — не засчитывать).
4. **Автозачёт на `speech.listen(4)`.** Цикл, отмена, выключение отклика на имя. Замер задержки.
5. **Свои слова игроков**, три раунда, «Горячее слово», режим «Команды».
6. **Непрерывное распознавание в оболочке** (`speech.stream`) — замер задержки до и после.
7. **Итоги вечера**, статистика игроков, запись в общую базу.

## Как проверить

1. `checks.js`: `matches()` на наборе пар «услышано — карточка» (точно, формы, основа, опечатка, словосочетание, ложные совпадения).
2. Тихая комната, владелец один: телефон показывает слово, владелец произносит его в разных падежах с расстояния 1 м и 3 м — доля зачётов и задержка (замер — время от конца слова на записи до вибрации; записывать экран и звук).
3. Тот же тест с музыкой из колонки на средней громкости и с двумя людьми, говорящими одновременно.
4. Ложные зачёты: объясняющий 60 с описывает слово, не называя его, — зачётов быть не должно (10 слов).
5. Слово на стыке кусков: сказать слово ровно на 4-й секунде — теряется ли (до правки оболочки).
6. Полная партия на 4 человека, 3 раунда — без сбоев, без повторов слов, счёт верный; сложить/раскрыть телефон между ходами — состояние не теряется (сохранение после каждого действия).
7. Батарея: процент до и после 30 минут игры с автозачётом.

## Риски и ограничения

- **Задержка зачёта** на текущем `speech.listen` — секунды; в живой игре это ощутимо. Хорошая версия требует правки оболочки.
- **Распознавание не различает говорящих** — нарушения правил ловят люди, а не телефон.
- **Шумная вечеринка** снижает точность; громкая музыка может сделать автозачёт бесполезным — тогда ручные кнопки.
- **Формы слов от модели** бывают неполными или ошибочными; правило окончаний и похожесть по Левенштейну страхуют, но дают редкие ложные зачёты коротких слов — поэтому для слов короче 6 букв похожесть выключена.
- **Батарея и нагрев** при часах непрерывного распознавания.
- **Микрофон занят** — нельзя одновременно с откликом на имя и живым разговором; модуль выключает их на время игры и обязан вернуть после (в том числе если экран закрыли посреди хода — `finally` и проверка при следующем запуске).
