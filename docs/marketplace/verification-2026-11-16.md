- [Assi](https://github.com/Billerens/assi) — PRIVATE.
- [Assi Store](https://github.com/Billerens/assi-store) — PUBLIC.

Публикация выполнена свежими снимками исходников. Старые локальные Git-истории сохранены в локальных ветках `local/pre-marketplace-2026-11-16` и не отправлены на GitHub. Основные рабочие папки связаны с опубликованными `origin/main`; файлы рабочего дерева сохранены. Ключи, `.env`, локальные настройки SDK, бэкапы, логи/БД/снимки экрана и персональные отчёты не включены в публикацию.

## Каталог

17 модулей и 23 игры; ZIP суммарно 3 791 587 байт. Все 40 архивов прошли настоящий Kotlin StoreInstaller: проверка, подготовка, применение, сохранение контрольных данных. Повторная сборка авторским CLI дала идентичные архивы и индекс. GitHub подтвердил SHA-256 всех 80 опубликованных assets.

SHA-256 `index.json`: `6a252ebba7b05cd8801cbde145fe2c604b8b45b89bc5e17c9bdf41f79ee0c014`.

`sparks-ring` остаётся в исходниках, но исключён из первого каталога из-за исторического runtime ID. Сохранения не переименованы. Общая открытая лицензия не выбрана; metadata использует `UNLICENSED`, сторонние лицензии сохранены.

## Автоматические проверки

- Полный JVM-прогон: 107 успешных тестов; дополнительный тест реального каталога включается отдельным параметром и тоже прошёл для всех 40 пакетов.
- Browser UI: 60 проверок, русский/английский, ширины 344/760/1280; без JS-ошибок и горизонтального переполнения.
- Python builder/metadata: 24 проверки; отдельный запуск публичной копии инструмента тоже успешен.
- Node-проверки игровых ID, каталога, web-транспорта/редактора/чата и mock-провайдера успешны.

## Эмулятор

Обновлён APK без очистки приложения. До тестов сохранена локальная резервная копия полезных данных эмулятора. Fold не использовался.

Реальный Android Native/Store путь проверен на тестовом репозитории: установка через физические нажатия, открытие модуля, обновление, локальные правки/добавления, конфликт, отклонение устаревшего плана, сохранение локальной версии, откат и сохранность данных. Удаление источника оставляет установленный код. Программируемый тестовый транспорт внедрялся только в память процесса средствами отладки; в поставке работает обычный HTTPS-клиент.

Отдельно настоящий Conversation прошёл путь проверки с детерминированным тестовым OpenAI-совместимым провайдером: ровно шесть разрешённых инструментов, отказ на `js_eval`, полное чтение, отчёт и применение. Маркер попытки запуска `checks.js` не появился. Это проверка механики, не семантический аудит стороннего кода языковой моделью. Исходные настройки модели восстановлены, тестовые пакеты и источник убраны.

Затем уже опубликованный GitHub-репозиторий добавлен через интерфейс с production HTTPS: видны все 40 пакетов, «Фокус» скачан, установлен и открыт; Snake Roguelike установлена и начала игровой забег. Попытка принять существующую локальную «Кузню» под управление магазина отклонена; её дескриптор не изменён.

На окончательном APK дополнительно проверена вся цепочка аудита опубликованного «Фокуса» с тем же тестовым провайдером: 21 файл, 63 ответа модели, успешное применение, исторический отчёт `completed/historicalOnly` сохранён. Настройки модели снова восстановлены. Файлы заводского интерфейса и справки извлечены из APK и побайтово сравнены с исходниками.

До запуска новой игры 54 из 56 прежних файлов данных эмулятора совпали побайтово. Два штатных фоновых модуля обновили только оперативные поля (`passenger.signals`, время `holidays.at`); сбросов сохранений/настроек не обнаружено. Контрольные данные тестового пакета выдержали все обновления и откат.

Локальные подробные отчёты: `build/artifacts/store-2026-11-16/`. Они не публикуются вместе с персональными артефактами.
