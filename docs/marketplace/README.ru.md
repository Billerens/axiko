# Контракты репозиториев и пакетов

Основная версия документации — английская. Русские переводы служат дополнением; при изменении
правила или формата обновляются обе версии. Схемы и машинные идентификаторы общие и не переводятся.

| Контракт | Основная английская версия | Русский перевод |
|---|---|---|
| Обязательный индекс, структура и лимиты пакета | [Repository format v1](repository-format-v1.md) | [Формат](repository-format-v1.ru.md) |
| Страницы каталога, описания, языки витрины | [Catalog pages](catalog-pages.md) | [Каталог](catalog-pages.ru.md) |
| Процесс проверки и привязка отчётов | [Agent review](agent-review.md) | [Проверка](agent-review.ru.md) |
| Коды правил, доказательства, уровни и бан выпуска | [Review rules](review-rules.md) | [Правила](review-rules.ru.md) |
| Установка, обновления, локальные правки, доверие | [Implementation](implementation.md) | [Реализация](implementation.ru.md) |
| Образцы модов и перенос правок на пакет-цель | [Mods](mods.md) | [Моды](mods.ru.md) |

Машинные схемы: [index](index.schema.json), [page](page.schema.json),
[details](details.schema.json), [package](package.schema.json). [Примеры метаданных](examples/)
используют заглушки адресов и хешей, это не выпуски для скачивания.

Для проверки метаданных и сборки используйте [author tools](../../scripts/store/README.md)
([русский перевод](../../scripts/store/README.ru.md)). Перед установкой стороннего пакета
прочитайте ограничения доверия: декларации возможностей и проверка моделью не создают песочницу runtime.
