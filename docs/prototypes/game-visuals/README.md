# Миры Аксико: 26 визуальных концепций

Интерактивные HTML-макеты для всех 13 игр из [визуального аудита](../../research/games-visual-audit-2026-11-15.md). По два композиционно разных направления на игру. Это предложения визуализации; игровые модули, баланс и сохранения в Аксико не изменяются.

Все направления получили положительную оценку пользователя. Обязательное уточнение для внедрения: **мир раскрывается вслед за реальной прогрессией, а большое число покупок и поздние этапы продолжают заметно менять его**. См. [правила визуальной прогрессии](PROGRESSION.md). Текущие макеты не моделируют полный путь развития игры.

## Открыть

**[standalone.html](standalone.html)** — вся галерея в одном файле, около 200 КБ. Открывается двойным кликом в современном браузере. Работает без сервера, интернета, библиотек, изображений и шрифтов из сети; файл можно переслать целиком.

[index.html](index.html) открывает ту же галерею из отдельных исходных файлов.

## Как смотреть

- Слева выберите игру. На телефоне список прокручивается горизонтально.
- **A / B** переключают композицию, мир и визуальный подход. Стрелки, Home и End также работают на вкладках.
- Кнопка под сценой разыгрывает действие: строительство, открытие, синтез, бой, полив или импульс. Последующие нажатия оставляют изменения в демонстрации.
- **Десктоп / Телефон** меняют ширину игрового экрана. Галерея также адаптируется к узкому окну браузера.
- **Пауза / Оживить** управляют движением; **Сброс** возвращает начальную демонстрацию выбранного варианта.
- **Выбрать направление** сохраняет ваш выбор для игры в этом браузере. Можно снять отметку или заменить её другим вариантом.
- **Все концепции** открывает обзор всех 26 сцен. Любая миниатюра ведёт к интерактивному макету.

## Направления

| Игра | A | B |
| --- | --- | --- |
| Династия | Королевство на ладони | Театр королевского двора |
| Библиотека | Дом тихих открытий | Обсерватория ненаписанных миров |
| Слои бесконечности | Каскад миров | Орбитальный сад |
| Алхимик | Мастерская после полуночи | Стеклянная микролаборатория |
| Зверинец | Стеклянный ковчег | Кубок заповедника |
| Башня | Башня в разрезе | Последний удар |
| Подземелье в одну клетку | Стол картографа | Свет под городом |
| Сад | Сад за старой калиткой | Оранжерея лунных цветов |
| Колония на астероиде | Тихая орбита | Под поверхностью |
| Сокровищница дракона | Хранитель горной пещеры | Бестиарий оживших легенд |
| Подземка | Город растёт | Город под городом |
| Последний рубеж | Дождевой квартал | Зелёный форпост |
| Искры в кольце | Орбитальный резонатор | Сердце машины |

В каждом варианте описано, что именно оживает и как движение связано с игровой механикой. Некоторые направления намеренно меняют метафору мира: например, книги как открывающиеся миры или алхимия как лабораторный синтез. Они демонстрируют художественный вариант, а не готовое расширение правил игры.

## От чего я бы оттолкнулся

Для первого внедрения: Династия A, Библиотека A, Слои бесконечности A, Алхимик A, Зверинец B, Башня B, Подземелье A, Сад A, Колония B, Дракон A, Подземка A, Последний рубеж A, Искры B.

В этих вариантах развитие мира или результат действия читаются особенно прямо. Для Зверинца питомник A можно оставить отдельным экраном размножения, для Подземки разрез B — режимом осмотра станции, а для Башни разрез A — экраном продвижения между боями. То есть полезные идеи из A и B можно совместить, не сводя весь интерфейс к одной сцене.

## Реализация и проверки

Сцены рисуются Canvas 2D, HUD и управление — HTML/CSS. Геометрия, свет, персонажи и частицы находятся в исходном коде. Демонстрационные числа и действия не подключены к Аксико. Выбор направлений хранится в `localStorage`; прогресс демонстраций живёт только до перезагрузки.

Анимируется только открытая сцена, с ограничением до 30 кадров/с. В скрытой вкладке, за пределами видимой области и в обзоре цикл остановлен. Системная настройка уменьшения движения включает статический режим; действие в нём показывает результат одним кадром. Измерений расхода аккумулятора на Android не проводилось.

Проверено в Chromium: 13 игр / 26 вариантов, 52 снимка широких и мобильных сцен, видимое изменение после действия, сброс, ширины 344/390/760 px без горизонтального переполнения страницы, движение и пауза, выбор направления после перезагрузки, обзор, навигация с клавиатуры. Дополнительно проверены skip-link, сохранение фокуса и контраст общего HUD. Отчёт и снимки: `build/artifacts/game-visual-concepts/` в корне проекта.

После изменения исходников собрать однофайловую версию через PowerShell 7:

```powershell
pwsh -NoProfile -File .\docs\prototypes\game-visuals\build-standalone.ps1
```
