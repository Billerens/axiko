# Башня

> Подъём по этажам, где каждый этаж — одна дверь из нескольких; десять этажей — один перегон,
> а погибший уносит вниз осколки для следующей попытки.

Сохранения, офлайн-прогресс, большие числа и рамка мета-прогрессии с престижем — общие, из
[`docs/modules/games.md`](../modules/games.md). Здесь только параметры этой игры. Все числа —
значения по умолчанию из конфига игры (`config.json`).

## Ядро

- На каждом этаже перед героем 2–3 двери. Над дверью виден её тип: бой, элита, сундук, событие,
  лавка, отдых. Выбор двери — главное решение этажа.
- Бой — короткая дуэль на 2–4 хода (10–20 секунд). У врага над головой намерение на этот ход:
  «удар 12», «защита 8», «заклятие», «зарядка». У героя в руке 3 приёма из его набора; за ход
  играется один. Приёмы: удар, блок, особые (из реликвий и класса).
- Порядок хода: игрок выбирает приём → оба действия разрешаются одновременно → враг показывает
  следующее намерение. Блок снимает урон, удар бьёт, у некоторых приёмов условие («если враг
  заряжается — ×3»).
- После боя: золото и опыт; при новом уровне — выбор из трёх даров (реликвия или усиление
  приёма).
- Забег кончается гибелью или выходом наружу после босса. Осколки начисляются в обоих случаях.

## Забег

- Башня — три пролёта по 10 этажей: **Подвалы**, **Галереи**, **Шпиль**. На 10-м этаже каждого
  пролёта — босс. Выше 30-го — бесконечные этажи «Над облаками» с ростом силы врагов.
- Пролёт — 2–3 минуты, ровно перегон. После босса развилка: «Спуститься» (осколки забираются
  целиком, забег закончен) или «Подняться дальше» (если погибнешь в следующем пролёте — уносишь
  только `deathKeep: 60%` осколков).
- Двери этажа выбираются по таблице весов (`doorWeights`): бой 45, событие 20, сундук 10,
  элита 10, лавка 8, отдых 7. Правила: 5-й этаж пролёта — всегда лавка или отдых на выбор;
  9-й — отдых; элиты не раньше 3-го этажа.
- Сила врага: `power(f) = 1 + 0.09·f + 0.002·f²` (`floorScaling`), где `f` — номер этажа.
- Цель длины: пролёт 2–3 мин, полный подъём на 30 этажей — 8–10 мин (три поездки или одна
  длинная).

## Выборы и сборки

Характеристики героя: здоровье, сила (урон удара), защита (сила блока), ловкость (шанс крита
и уклонения), воля (заряды особых приёмов на бой).

Приёмы (10) — даются классом или дарами, усиливаются до +2:

1. **Удар** — урон = сила.
2. **Блок** — снимает урон до значения защиты.
3. **Выпад** — урон ×1.5, но этот ход без блока.
4. **Отражение** — блок; излишек блока возвращается врагу уроном.
5. **Подсечка** — урон ×0.5, следующее намерение врага слабеет на 50%.
6. **Рывок** — удар, который всегда ходит первым; если убил — ход не кончается.
7. **Чтение** — показывает два следующих намерения врага на весь бой.
8. **Пламя** — 2 урона за ход до конца боя, складывается.
9. **Передышка** — +15% здоровья, расходует 1 волю.
10. **Казнь** — если у врага меньше 25% здоровья, убивает сразу.

Реликвии (28). Редкость: О — обычная, Р — редкая, Л — легендарная.

| Реликвия | Ред. | Эффект |
|---|---|---|
| Медная пряжка | О | +5 здоровья, +1 защита |
| Точильный камень | О | +2 сила |
| Подкова | О | +5% уклонения |
| Кошель с дыркой | О | +20% золота, но 1 монета теряется за этаж |
| Масляная лампа | О | Видно третью дверь на этажах, где их две |
| Сухари | О | Отдых лечит на 10% больше |
| Перо ворона | О | После боя без урона +5 золота |
| Счёты | О | Цены в лавке −15% |
| Узел на память | О | Первое событие пролёта показывает исход каждой строки |
| Колокольчик | О | Начало боя: враг теряет 3 здоровья |
| Стеклянный глаз | Р | Видно два намерения вперёд всегда |
| Двойная тетива | Р | Удар бьёт дважды по 60% |
| Тёплый камень | Р | Каждый 3-й ход +1 воля |
| Зеркальный щит | Р | Отражение возвращает ×2 |
| Карта этажей | Р | Двери видны на 2 этажа вперёд |
| Спящая змея | Р | Пламя накладывается и при ударе |
| Цепь | Р | Убийство переносит 50% излишнего урона на следующего врага пролёта |
| Ржавый ключ | Р | Сундуки дают выбор из 2 реликвий |
| Песочные часы | Р | Первый ход каждого боя враг пропускает |
| Кровавая монета | Р | Лавка принимает здоровье вместо золота: 1 здоровье = 3 золота |
| Колода судьбы | Р | Рука приёмов — 4 карты вместо 3 |
| Вторая тень | Л | Каждый приём повторяется с силой 40% |
| Корона без камня | Л | +1 к выбору даров (из четырёх), −10% здоровья |
| Сердце башни | Л | Раз за забег: смерть → 30% здоровья |
| Пустой фонарь | Л | Элиты считаются обычным боем, но дают награду элиты |
| Обет тишины | Л | Нельзя блокировать; удар ×2 |
| Флюгер | Л | Можно поменять тип одной двери на этаже раз за пролёт |
| Мешок мелочи | Л | Каждые 100 золота — +1 сила до конца забега |

Нарочно сломанные сочетания:

- **Отражение + Зеркальный щит + Вторая тень** — враги убивают себя сами о блок.
- **Рывок + Цепь + Двойная тетива** — один бой длиной в ход, излишек пробивает весь пролёт.
- **Кровавая монета + Сердце башни + Сухари** — лавка опустошается целиком, здоровье
  восстанавливается на отдыхе.

События (стартовый набор 15, текст — данные): «Колодец желаний» (бросить 20 золота: 50% —
реликвия), «Раненый страж» (вылечить — потом поможет в бою с боссом), «Голос за стеной»
(обменять приём на другой случайный), «Лестница без перил» (−10 здоровья, пропустить этаж),
«Книжная полка» (+1 к приёму или 30 золота) и другие.

## Враги и препятствия

| Враг | Пролёт | Намерения |
|---|---|---|
| Крысолов | Подвалы | Удар 5 / удар 5 / защита 4 по кругу |
| Плесневик | Подвалы | Каждый ход +2 к своему удару, мало здоровья |
| Сторож с фонарём | Подвалы | Зарядка → удар ×3; блок вовремя обнуляет |
| Цепной пёс | Подвалы | Два удара по 3 за ход |
| Гобеленщик | Галереи | Заклятие: прячет следующее намерение |
| Двойник | Галереи | Повторяет прошлый приём героя |
| Каменный ученик | Галереи | Защита 10 каждый 2-й ход, иначе удар 9 |
| Вор | Галереи | Удар крадёт 10 золота; убежит на 4-м ходу |
| Флюгерный рыцарь | Шпиль | Меняет намерение, если герой блокирует |
| Ветряная дева | Шпиль | Уклоняется от каждого второго удара |
| Часовщик | Шпиль | Через 3 хода «полночь» — удар 40 |
| Эхо героя | Шпиль | Копия героя с его приёмами на 70% |

Элиты — враг пролёта ×2.5 здоровья, плюс одно свойство из списка (`eliteMods`): шипы, лечение,
двойной ход раз в бой.

Боссы:

- **Привратник подвалов** — щит из 3 пластин; каждая снимается блоком в ход его удара.
- **Хозяйка галерей** — каждые 2 хода меняет облик: в одном бьёт, в другом лечится.
- **Ключник шпиля** — запирает один приём героя каждый ход; на 50% здоровья запирает два.

## Мета-прогрессия

Валюта — **осколки**: `этаж·2 + 15 за босса + 5 за элиту`, при спуске — 100%, при гибели —
`deathKeep`.

«Лестничная мастерская», цена `cost(n) = base · 1.4^n`. Закалка, Хватка, Стойка и Кошелёк не
имеют последнего уровня: до порога мастерства цена растёт как у всех (×1,4), после него каждый
следующий уровень стоит ×1,7 от предыдущего (`workshop.lateGrowth`), то есть
`cost(n) = base · 1.4^порог · 1.7^(n − порог)`. Остальные четыре улучшения упираются в предел по
смыслу: ловкость ограничена `combat.agilityCap`, воля меняет экономику боя, дверь и память —
разовые открытия.

| Улучшение | Эффект за уровень | Предел | Порог мастерства | base |
|---|---|---|---|---|
| Закалка | +5 здоровья | нет | 10 | 10 |
| Хватка | +1 сила | нет | 5 | 25 |
| Стойка | +1 защита | нет | 5 | 25 |
| Чутьё | +3% ловкости | 5 | — | 30 |
| Запас воли | +1 воля | 3 | — | 60 |
| Кошелёк | +15 стартового золота | нет | 5 | 15 |
| Знание дверей | +1 дверь на первом этаже пролёта | 2 | — | 80 |
| Память | 70% / 80% осколков при гибели | 2 | — | 120 |

Точки баланса («максимум») считаются на пороге мастерства: предельные улучшения куплены
целиком, бесконечные — до порога. Уровни выше порога — долгий сток осколков для высот и
подъёма за тридцатый этаж: шестой уровень Хватки стоит 135 осколков, десятый — 1123, одиннадцатый уровень Закалки — 290.

Классы: **Страж** (Блок+, Отражение; есть сразу), **Лучница** (Двойная тетива на старте,
меньше здоровья; открыть — пройти Подвалы), **Книжник** (Чтение и +1 воля; пройти Галереи),
**Поджигатель** (Пламя ×2; убить 100 врагов Пламенем), **Безымянный** (случайная рука каждый
бой; пройти Шпиль).

Высоты (ступени сложности, аналог престижного цикла общей рамки), 1–12: после прохода Шпиля
открывается следующая. Примеры: «враги начинают со щитом 3», «лавки дороже на 25%», «отдых
лечит вдвое меньше», «боссы получают вторую фазу». Каждая высота — +10% осколков.

## Темп

- Первый забег: гибель на 5–8-м этаже, 15–20 осколков — хватает на 1–2 улучшения.
- Первый час: проход Подвалов, второй класс, знакомство с 15 реликвиями.
- Первая неделя: проход Шпиля, 3–4 класса, высоты 2–4.
- Гибель — прогресс: осколки, счётчик «самый высокий этаж» на каждом классе, открытые в
  альбоме реликвии, события и встреченные враги.

## Экран и управление

- Портрет. Верх — этаж и пролёт, середина — сцена (враг или дверь), низ — рука приёмов, всё в
  зоне большого пальца.
- Шкала пролёта: десять этажей, пройденные залиты, текущий подсвечен; над пятым этажом стоит
  значок лавки, над девятым — отдыха, над десятым — босса; под шкалой подпись «Этаж N из 10 в
  пролёте» и «До босса: N». У подножия башни вместо неё — три пролёта (Подвалы, Галереи, Шпиль)
  с заполнением по лучшему подъёму, рекордный этаж и открытая высота.
- Двери — три вертикальные серые карточки в ряд с пиктограммой типа и подписью. На внешнем
  экране — столбиком.
- Бой: намерение врага — крупная пиктограмма с числом над ним; приёмы — карточки снизу,
  нажатие — сыграть, долгое нажатие — описание.
- Развёрнутый экран: слева сцена, справа реликвии и журнал боя.
- Вид — рисованные SVG-картинки (`ui/art.js`, поле 48×48, одна палитра, светлый контур, плоские
  заливки, без текста) на тёмном фоне, каждый пролёт со своим приглушённым оттенком (Подвалы —
  холодный серо-зелёный, Галереи — охра, Шпиль — серо-синий). Без теней и эмодзи.
- Своя картинка есть у каждого приёма, реликвии, класса, врага и босса, двери, события,
  улучшения мастерской, высоты, намерения врага и у ресурсов. Рамка картинки говорит о редкости
  реликвии (синяя — редкая, золотая — легендарная) и об опасности (фиолетовая — элита, красная —
  босс). Закрытое — серый силуэт с замком в пунктирной рамке, купленное до предела — с галочкой.
- Сцена — кладка стены в оттенке пролёта; у подножия и перед дверьми на ней башня из трёх
  пролётов, где залиты те, до которых герой добирался.
- Альбом: рекорды классов, реликвии, враги и боссы (открываются при первой встрече), встречи.

## Прерывание и офлайн

- Сохранение после каждого действия: выбор двери, приём, покупка. Состояние маленькое, снимок
  делается целиком.
- После убийства приложения — тот же этаж и тот же ход; генератор случайных чисел — из сохранения,
  так что «перезапуск ради лучшего сундука» ничего не меняет.
- Офлайн: в забеге ничего не идёт. Своего пассивного дохода нет.

## Связки с Axiko

- `passenger.md` — в поездке без сети: осколки ×2; поездка длиннее 20 минут — дополнительный
  сундук в начале следующего пролёта.
- `steps-fuel.md` — заряд от шагов: «Свежие ноги» — первый отдых пролёта лечит полностью.
- `daily-bet.md` — ставка осколками.
- Ачивки: «Над облаками» (этаж 31), «Без блока» (пройти пролёт, ни разу не заблокировав),
  «Все двери» (каждая дверь каждого типа за забег), «Высота 12».
- Модель, пока есть сеть: события (текст, 2–3 выбора, исходы из готовых эффектов — проверяются
  схемой), башня дня (общее зерно, особое правило), новые враги из готовых шаблонов намерений.

## Как проверить

- Симулятор: бот выбирает двери по простой оценке (здоровье ниже 40% → отдых), в бою играет
  блок против удара и удар иначе. 2000 забегов на точку.
- Цели доли прохода пролёта: пустая мастерская — Подвалы 30%, Шпиль 2%; середина — Подвалы
  80%, Шпиль 25%; максимум, высота 0 — Шпиль 75%; высота 12 при максимуме — 15%. «Максимум» —
  предельные улучшения целиком, бесконечные — на пороге мастерства.
- Длина: средний бой 2–4 хода; пролёт у бота при реальных задержках нажатий — 2–3 минуты.
- На телефоне: все приёмы и двери достаются большим пальцем на внешнем экране; переход
  между этажами — меньше 300 мс; force-stop посреди боя возвращает тот же ход.

## Открытые вопросы

- Дуэль с приёмами (как описано) или бой целиком автоматический, а решение — только дверь?
- Сколько осколков сохранять при гибели после развилки «дальше»?
- Нужны ли бесконечные этажи или достаточно 30 и высот?
