# Подземелье в одну клетку

> Спуск по сетке 3×3, где герой — одна из девяти карт, каждый шаг съедает соседнюю карту, а
> освободившееся место тут же занимает следующая из колоды спуска.

Сохранения, офлайн-прогресс, большие числа и рамка мета-прогрессии с престижем — общие, из
[`docs/modules/games.md`](../modules/games.md). Здесь только параметры этой игры. Все числа —
значения по умолчанию из конфига игры (`config.json`).

## Ядро

- Поле — 3×3 открытые карты. Одна из них — герой. Ход — нажать карту по соседству по стороне
  (не по диагонали): герой переходит на её место, карта срабатывает.
- Клетка, которую герой покинул, тут же заполняется верхней картой **колоды спуска** — новая
  карта всегда появляется у героя за спиной, впереди видно то, что уже лежит.
- У героя: **здоровье** (на старте 12), **оружие** (сила и заряды), **щит** (запас, сгорает
  первым), **золото**, **рука** из двух даров (см. ниже).
- Бой с врагом силы `V`: враг всегда погибает; урон герою `max(0, V − сила оружия)`, сначала в
  щит, остаток — в здоровье; оружие теряет 1 заряд, на нуле ломается.
- **Хищники**: после каждого хода каждый хищник по соседству с героем бьёт на 1. Порядок шагов
  решает больше, чем сила.
- Колода этажа кончилась — покинутые клетки остаются пустыми (на пустую можно шагнуть, ничего
  не происходит), а на первой из них появляется лестница. Лестница может выпасть и раньше
  (замешана в последнюю треть колоды): шагнуть сразу или сначала добрать карты.
- Здоровье на нуле — забег окончен. Пройти пятый этаж — победа.
- Ход — около секунды раздумий, этаж — 25–30 секунд, забег — около 2–3 минут.

## Забег

| Этаж | Карт в колоде | Состав (враги / полезное / прочее) | Новое |
|---|---|---|---|
| 1 Погреб | 16 | 50% / 40% / 10% | — |
| 2 Склеп | 18 | 55 / 35 / 10 | Хищники |
| 3 Колодец | 20 | 55 / 30 / 15 | Ловушки, сундуки с ключами |
| 4 Корни | 22 | 60 / 30 / 10 | Враги-с-панцирем |
| 5 Сердце | 18 + хозяин | 60 / 30 / 10 | Хозяин глубины |

- Сила врагов этажа: `V ∈ [1 + этаж, 4 + 2·этаж]` (`enemyRange`).
- После каждого этажа — выбор одной **печати** из трёх и привал: +3 здоровья или лавка
  (зелья, оружие, обмен даров).
- Честность раздачи: генератор прогоняет колоду этажа простым ботом 200 раз (`fairRuns`); если
  бот с текущим состоянием героя выживает реже 50% (`fairMin`), одна вражеская карта заменяется
  зельем, и проверка повторяется.
- После победы — «Ниже дна»: этажи без конца с растущими силами врагов, счёт — этажи.

## Выборы и сборки

Карты колоды спуска (базовые):

| Карта | Действие |
|---|---|
| Враг `V` | Бой (см. выше) |
| Хищник `V` | Как враг, плюс бьёт на 1, стоя рядом с героем |
| Панцирник `V` | Оружие слабее `V/2` наносит ему только половину |
| Зелье `N` | +N здоровья (не выше наибольшего) |
| Оружие `S×C` | Заменяет текущее: сила S, заряды C |
| Щит `N` | +N к щиту (не больше 10) |
| Золото `N` | +N золота |
| Ловушка `N` | −N здоровья, щит не помогает |
| Ключ | +1 ключ |
| Сундук | Без ключа — просто пустеет; с ключом — выбор из 2 печатей или 15 золота |
| Алтарь | Отдать 3 здоровья → +1 заряд оружию и +1 к силе |

Дары — карты собственной колоды владельца, в руке два, каждый срабатывает раз за этаж:

1. **Обмен** — поменять местами две любые карты поля (не героя).
2. **Подкова** — превратить врага в золото той же величины.
3. **Пустой шаг** — шагнуть на клетку, не срабатывая карту; она остаётся.
4. **Глоток** — +3 здоровья.
5. **Точило** — +2 заряда оружию.
6. **Взгляд** — показать 3 следующие карты колоды.
7. **Удар издали** — убить врага на любой клетке силой оружия, не двигаясь.
8. **Тишина** — хищники не бьют 3 хода.
9. **Сжатие** — убрать одну карту поля в низ колоды.
10. **Двойной шаг** — два хода подряд, хищники бьют только после второго.

Печати — пассивные до конца забега. О — обычная, Р — редкая, Л — легендарная.

| Печать | Ред. | Эффект |
|---|---|---|
| Кожаный ремень | О | +3 к наибольшему здоровью |
| Крепкая рукоять | О | +1 заряд каждому новому оружию |
| Медный котёл | О | Зелья +1 |
| Копилка | О | Золото +1 с каждой карты золота |
| Чуткий сон | О | Первая ловушка этажа не срабатывает |
| Ржавый засов | О | Щит с каждой карты щита +1 |
| Отмычка | Р | Сундук открывается без ключа раз за этаж |
| Кровопийца | Р | Убив врага без урона себе — +1 здоровье |
| Встречный удар | Р | Хищник, ударивший героя, получает 2 урона; погиб — превращается в золото |
| Вторая рука | Р | В руке три дара |
| Счётная доска | Р | Видна следующая карта колоды |
| Тихий шаг | Р | Хищники бьют только с двух сторон и больше |
| Зеркальный клинок | Р | Сломанное оружие оставляет щит, равный его силе |
| Запасной клинок | Р | Найденное оружие слабее текущего не заменяет его, а даёт +1 заряд |
| Дыхание глубины | Р | Лестница выпадает на 30% раньше |
| Голод | Р | Зелья вместо лечения дают +1 к наибольшему здоровью |
| Алчность | О | Лавка −20%, враги +1 к силе |
| Каменная кожа | Л | Урон больше 5 за раз срезается до 5 |
| Тень героя | Л | Покинутая клетка остаётся пустой на один ход: за спиной ничего не появляется |
| Отзвук | Л | Каждый дар срабатывает дважды за этаж |
| Последний вдох | Л | Раз за забег: смерть → здоровье 1 и щит 5 |
| Мастер клинка | Л | Оружие не теряет заряд, если сила ≥ силы врага |

Нарочно сломанные сочетания:

- **Мастер клинка + Алтарь + Крепкая рукоять** — одно хорошее оружие проходит весь забег.
- **Встречный удар + Каменная кожа + Голод** — хищники кормят героя золотом, а зелья делают
  его вечным.
- **Отзвук + Удар издали + Подкова** — этаж проходится, не подходя ни к одному врагу.

## Враги и препятствия

| Враг | Этажи | Особенность |
|---|---|---|
| Плесень | 1–2 | Обычный враг 2–4 |
| Крыса-сторож | 1–3 | Хищник 2–3 |
| Костяной пёс | 2–4 | Хищник; когда рядом второй хищник, +2 к силе |
| Слепень | 2–4 | Убитый, оставляет на своей клетке ловушку 1 |
| Медный жук | 3–5 | Панцирник |
| Вор-тень | 3–5 | Уносит 5 золота, если герой прошёл рядом и не убил |
| Корневик | 4–5 | После каждого хода +1 к силе, пока жив |
| Двойник | 4–5 | Сила равна силе оружия героя + 1 |
| Колдунья | 3–5 | Пока на поле, зелья действуют вдвое слабее |

**Хозяин глубины** (5-й этаж): занимает клетку и не исчезает после боя — у него 30 здоровья,
каждый бой снимает с него силу оружия, а герою бьёт на 6 (минус оружие и щит). После хода
героя хозяин меняется местами с соседней случайной картой. На 15 здоровья призывает двух крыс.
Убит — победа.

## Мета-прогрессия

Валюта — **угли**: `золото / 5 + 3 за этаж + 20 за хозяина`.

Колода даров: владелец открывает и улучшает дары, перед забегом берёт в руку два (с печатью
«Вторая рука» — три). Сокровищница — «дары колоды спуска»: добрые карты, которые замешиваются в
колоду спуска каждого этажа (например, «Знакомый кузнец» — оружие 4×3, «Тёплый очаг» — зелье 5);
слотов 2, открывается до 6.

| Что | Эффект | Макс | Цена |
|---|---|---|---|
| Новый дар | Открыть дар из списка | 10 | 30 · 1.3^n |
| Уровень дара | Дар сильнее (Глоток +3 → +4 → +5 и т.п.) | без предела | 40 · 2^ур |
| Слот колоды спуска | +1 добрая карта | 4 | 50 · 1.6^n |
| Крепость | +1 здоровье на старте | без предела | 15 · 1.4^n |
| Стартовый клинок | Оружие 2×2 на старте | 1 | 80 |

Герои:

- **Стражник** — 12 здоровья. Есть сразу.
- **Воровка** — 10 здоровья, ключ на старте, золото ×1.5. Пройти Склеп.
- **Жрица** — зелья ×1.5, у оружия на заряд меньше. Пройти Корни.
- **Кузнец** — заряды оружия +1, 10 здоровья. Сломать 30 оружий за всё время.
- **Безумец** — щит недоступен, сила оружия +2. Победа.

Глубины (ступени, престижный цикл общей рамки), 1–10: «враги +1», «зелий меньше», «хищники
с первого этажа», «хозяин с 40 здоровья»… Каждая — +10% углей.

## Темп

- Первый забег: гибель на 2–3-м этаже за минуту с небольшим, 10–15 углей — первый новый дар.
- Первый час: 15–20 забегов, первая победа, 2 героя, 5 даров.
- Первая неделя: все герои, глубины 3–5, рекорд «Ниже дна».
- Поражение — тоже прогресс: угли, открытые печати в альбоме, счётчики условий героев.

## Экран и управление

- Портрет. Сетка 3×3 — в нижних двух третях экрана, вся под большим пальцем; сверху —
  здоровье, щит, оружие (сила и заряды точками), золото, номер этажа и остаток колоды.
- Рука даров — две карточки между сеткой и верхней панелью; нажать дар → подсветка возможных
  целей → нажать цель. Отмена — повторное нажатие на дар.
- Карта, куда нельзя шагнуть, затемнена. Долгое нажатие на любую карту — её описание.
- Предпросмотр хода: при касании соседней карты на 200 мс показывается итог («−3 здоровья,
  оружие 1 заряд»); палец отпущен — ход сделан, уведён в сторону — отменён.
- Внешний экран: сетка во всю ширину, карты почти квадратные. Развёрнутый: сетка в центре,
  слева печати, справа журнал ходов и верх колоды (если виден).
- Вид: карты — нейтрально-серые прямоугольники с крупным числом и SVG-пиктограммой типа,
  враги с тёмно-красной полосой, полезное — с приглушённо-зелёной, хищники — с зубчатым краем.
  Переход героя — 120 мс. Без теней и эмодзи.

## Прерывание и офлайн

- Пошаговая игра: сохранение после каждого хода и каждого дара — поле, колода по порядку,
  герой, генератор случайных чисел.
- Убили приложение — тот же ход. Колода хранится уже перемешанной, перезапуск ничего не
  меняет.
- Офлайн в забеге ничего не идёт, своего пассивного дохода нет.

## Этапы

1. MVP: Стражник, сетка, колода спуска, враги / зелья / оружие / щит / золото, лестница,
   5 этажей без хозяина, сохранение каждого хода.
2. Хищники, ловушки, ключи и сундуки, алтарь.
3. Печати между этажами, привал и лавка.
4. Дары и рука, колода даров и угли.
5. Хозяин глубины, герои, глубины, «Ниже дна».
6. Проверка честности раздачи, спуск дня, контент от модели, связки с жизнью.

## Как проверить

- Симулятор: бот оценивает каждый соседний ход на 2 шага вперёд по формуле «здоровье + щит +
  ценность оружия». 5000 забегов на точку.
- Цели доли побед: без даров и улучшений — 10%; середина — 45%; всё открыто, глубина 0 — 85%;
  глубина 10 — 15%. Длина забега у бота при 1 с на ход — 2–3 минуты.
- Проверка «колода решает»: разница доли побед между ботом на 2 шага и случайным ботом —
  не меньше 30 пунктов, иначе выборы ничего не значат.
- На телефоне: все карты и дары достаются большим пальцем на внешнем экране; предпросмотр не
  мешает быстрым ходам; force-stop — тот же ход.

## Открытые вопросы

- Новая карта появляется за спиной героя (как описано) или в случайной пустой клетке?
- Нужен ли предпросмотр итога хода или он делает игру слишком лёгкой?
- Сколько даров в руке на старте: два или один?
