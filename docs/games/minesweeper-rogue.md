# Сапёр-рогалик

> Сапёр без угадывания: поле всегда можно разгадать логикой, а между полями собираются
> инструменты и талисманы против всё более хитрых мин.

Сохранения, офлайн-прогресс, большие числа и рамка мета-прогрессии с престижем — общие, из
[`docs/modules/games.md`](../modules/games.md). Здесь только параметры этой игры. Все числа —
значения по умолчанию из конфига игры (`config.json`).

## Ядро

- Поле из клеток. Нажатие открывает клетку: число — сколько мин среди восьми соседей. Пустая
  клетка открывает соседей сама.
- Долгое нажатие (`flagHoldMs: 300`) ставит флаг. Нажатие по открытому числу, вокруг которого
  флагов столько же, сколько мин, открывает остальных соседей.
- Наступил на мину — не смерть: гаснет одно **сердце** (на старте 3), мина помечается. Сердца
  кончились — забег окончен.
- Поле пройдено, когда открыты все безопасные клетки. Среди безопасных спрятаны **тайники**:
  золото или находка.
- После поля — выбор одной **находки** из трёх (инструмент или талисман); после слоя — лавка.
- Поле разгадывается за 25–45 секунд. Таймера нет.

## Забег

- Три слоя по два поля и поле-хозяин в конце: всего 7 полей, 4–5 минут.

| Слой | Поля (столбцы × строки, мины) | Новое |
|---|---|---|
| Дёрн | 7×9 / 10, 8×11 / 14 | Только обычные мины |
| Глина | 8×12 / 18, 9×13 / 22 | Двойные мины, глухие клетки |
| Скала | 9×14 / 26, 9×16 / 30 | Бродячие и часовые мины, провалы |
| Хозяин | 9×16 / 28 + особое правило | См. ниже |

- Ширина поля — не больше 9 столбцов (`maxCols`), чтобы на внешнем экране клетка была не меньше
  7 мм. Длинные поля прокручиваются по вертикали.
- После Скалы — «Глубже»: бесконечные поля с ростом плотности мин `+0.5%` за поле, счёт —
  пройденные поля.

### Поля без угадывания

Каждое поле проверяется решателем до того, как попадёт к игроку.

1. **Первое нажатие безопасно.** Поле генерируется после него: из квадрата 3×3 вокруг клетки
   мины исключены, так что первым ходом открывается область. Расклад детерминирован зерном
   забега и координатой касания.
2. **Решатель** повторяет ровно то, что может сделать человек, по видимым клеткам:
   - простое правило: у числа скрытых соседей столько же, сколько недостающих мин — все мины;
     мин уже хватает — остальные безопасны;
   - правило пары: если скрытые соседи одного числа — подмножество соседей другого, разница
     чисел относится к разнице клеток;
   - перебор границы: граница делится на связные куски; кусок до 24 клеток (`enumLimit`)
     перебирается полностью, клетка, которая во всех вариантах мина (или во всех пуста),
     считается выведенной; в конце учитывается общее число мин.
3. **Починка.** Решатель застрял — одна мина с застрявшего участка переносится во внутреннюю
   клетку подальше от открытого, и проверка начинается заново. До 40 попыток
   (`repairTries`) в бюджете 80 мс (`genBudgetMs`).
4. **Запас.** Поля готовятся заранее в Web Worker, пока игрок разгадывает текущее; в запасе
   всегда 2 поля (`pregen`), переход между полями мгновенный.
5. **Если не вышло.** Поле всё равно принимается, но в точке, где решатель застрял, игра
   сама отмечает одну безопасную клетку знаком «подсказка земли». Угадывать не приходится
   никогда; такие поля считаются в статистике, их доля должна быть меньше 1%.
6. **Особые мины** в решателе:
   - двойная мина считается в числах за две — решатель работает со значениями 0/1/2;
   - глухая клетка (число не показано) — для решателя просто нет сведений;
   - бродячая мина перед шагом перебирает соседние скрытые клетки и идёт только туда, где поле
     остаётся разгадываемым; таких нет — стоит;
   - часовая мина начинает отсчёт только с момента, когда её можно вывести из открытого, —
     отсчёт всегда честный.

## Выборы и сборки

Инструменты — расходуемые, с зарядами (в скобках — заряды при получении).

| Инструмент | Ред. | Действие |
|---|---|---|
| Щуп (2) | О | Показывает, мина ли в клетке, не открывая её |
| Рентген (1) | Р | Открывает клетку безопасно: мина — ставится флаг |
| Лопата (1) | Р | Квадрат 3×3: безопасное открывается, мины помечаются |
| Фонарь (2) | О | Показывает число мин в квадрате 5×5 |
| Компас (2) | О | Стрелка на ближайшую непомеченную мину |
| Сигнальная ракета (1) | Р | Помечает все мины одной строки |
| Заплатка (1) | О | +1 сердце |
| Песок (1) | О | Бродячие мины замирают до конца поля |
| Стоп-кран (1) | Р | Останавливает все часовые мины поля |
| Сейсмограф (1) | Л | Слева у каждой строки — число мин в ней до конца поля |

Талисманы — постоянные до конца забега:

| Талисман | Ред. | Эффект |
|---|---|---|
| Толстые сапоги | О | +1 к наибольшему числу сердец |
| Дубовый щит | Р | Первая мина каждого поля не стоит сердца |
| Чутьё | Р | При нажатии на мину раз за поле — клетка дрожит, нажатие отменяется |
| Подмастерье | Л | После каждого хода ставит флаги на мины, выводимые простым правилом |
| Аккуратист | О | +1 золото за каждый верный флаг |
| Золотая жила | О | Тайники дают +50% золота |
| Нюх на клады | Р | Тайники видны слабым узором до открытия |
| Широкий шаг | О | Первое нажатие открывает область не меньше 12 клеток |
| Пояс с карманами | О | +1 заряд каждому новому инструменту |
| Медленный маятник | О | Часовые мины тикают вдвое медленнее |
| Тяжёлые шаги | Р | Бродячие мины ходят вдвое реже |
| Двойное зрение | Р | Двойные мины видны как «2» на флаге после первого соседа |
| Тихая лавка | О | Цены в лавке −20% |
| Свеча в шахте | О | Глухие клетки показывают число, если рядом поставлен флаг |
| Карта прошлого | Р | Поле-хозяин показывает своё правило слоем раньше |
| Запасное сердце | Л | Раз за забег: потеря последнего сердца → 2 сердца |
| Жадная кирка | Р | Каждое поле без потерь сердец — +1 заряд случайному инструменту |
| Лёгкая рука | О | Флаг ставится коротким нажатием, открытие — долгим (переключатель) |
| Осколок карты | О | В начале поля открыта ещё одна безопасная клетка с числом |
| Счётчик мин | О | В углу — сколько мин осталось без флага |

Нарочно сломанные сочетания:

- **Подмастерье + Лопата + Рентген** — поле разгадывается почти само; игрок только жмёт.
- **Дубовый щит + Чутьё + Заплатка** — можно нажимать быстро и наугад; за это теряется только
  золото «Аккуратиста».
- **Аккуратист + Двойное зрение на Глине** — двойная мина приносит 2 золота за флаг.

## Враги и препятствия

| Мина / клетка | Поведение |
|---|---|
| Обычная мина | −1 сердце |
| Двойная мина | Считается за 2 в числах, −2 сердца |
| Бродячая мина | Каждые 5 открытий (`roamEvery`) переходит в соседнюю скрытую клетку; числа обновляются, перед шагом клетка мерцает |
| Часовая мина | Должна быть помечена за 12 открытий с момента, как её можно вывести, иначе взрывается сама: −1 сердце |
| Глухая клетка | Открыта, но число скрыто |
| Провал | Не клетка: дыра в форме поля, у соседей меньше восьми клеток |
| Ложный тайник | Выглядит как тайник через «Нюх на клады», внутри — ничего |

Хозяева (последнее поле, одно правило из пула `bosses`):

- **Наоборот** — числа показывают безопасных соседей, а не мины.
- **Рой** — пять бродячих мин, шаг каждые 3 открытия.
- **Двойное дно** — половина мин двойные.
- **Туман** — открыты только числа в радиусе 2 от последнего хода, остальное сереет (но
  запоминается флагами).

## Мета-прогрессия

Валюта — **руда**: `поля·4 + золото/10 + 15 за хозяина + 10 за поле без потерь`.

Мастерская, цена `cost(n) = base · 1.4^n`:

| Улучшение | Эффект | Макс | base |
|---|---|---|---|
| Крепкое сердце | +1 сердце на старте | 2 | 80 |
| Запасы | Стартовый инструмент: Щуп (1) → Щуп (2) → + Фонарь | 3 | 30 |
| Мешочек | +15 стартового золота | без предела | 10 |
| Широкий выбор | 4 находки вместо 3 | 1 | 150 |
| Скидка | −5% цен | 4 | 25 |
| Удача клада | +10% тайников | 5 | 20 |

Сапёры (аналог героев):

- **Сапёр** — без особенностей. Есть сразу.
- **Геолог** — Фонарь (3) на старте, на одно сердце меньше. Пройти Глину.
- **Картограф** — видит провалы и тайники с первого хода. Пройти забег.
- **Взрывник** — мина отнимает сердце, но даёт 10 золота. 50 мин взорвано за всё время.
- **Чистюля** — 2 сердца, зато руда ×1.5. Пройти забег без потерь сердец на Скале.

Режимы: «Чистый сапёр» (поля растут, без находок и мин-хитрецов, только логика); «Глубже».
Глубины (ступени, престижный цикл общей рамки), 1–12: «+10% мин», «тайники реже», «бродячие
появляются уже в Глине», «хозяин с двумя правилами»… Каждая — +10% руды.

## Темп

- Первый забег: гибель на Глине, 15–25 руды — первое улучшение.
- Первый час: первая победа, Геолог, первые 15 находок.
- Первая неделя: все сапёры, глубины 3–5, рекорд «Глубже».
- Поражение — тоже прогресс: руда, альбом находок, счётчик «всего разгадано клеток».

## Экран и управление

- Портрет. Поле — сверху во всю ширину; снизу полоска инструментов (до 5 кнопок) и переключатель
  «открыть / флаг» — всё в зоне большого пальца.
- Прокрутка длинного поля — вертикальным ведением; случайное открытие при прокрутке отсекается:
  касание с движением больше 8 px не открывает.
- Внешний экран: 9 столбцов, клетка ≥ 7 мм. Развёрнутый: поле целиком без прокрутки, справа —
  талисманы.
- Вид: клетки — нейтрально-серые квадраты с тонкой границей, открытые — темнее; числа в
  приглушённой шкале цветов (1 — серо-синий … 6 — тёмно-красный), всегда разной насыщенности,
  чтобы читались без цвета. Мины и флаги — простые SVG-формы. Без теней и эмодзи.

## Прерывание и офлайн

- Сохранение после каждого открытия и флага: поле, мины, отсчёты, генератор случайных чисел,
  запас полей.
- Убили приложение — то же поле, те же флаги. Запас полей при необходимости пересоздаётся из
  зерна — те же самые поля.
- Офлайн в забеге ничего не идёт; своего пассивного дохода нет.

## Связки с Axiko

- `passenger.md` — в поездке без сети руда ×2.
- `steps-fuel.md` — заряд от шагов: Щуп (2) в начале забега.
- `daily-bet.md` — ставка рудой.
- Ачивки: «Без единой ошибки» (забег без потерь сердец), «Ни одной подсказки» (забег без
  инструментов), «Глубина 12», «10 000 клеток».
- Модель, пока есть сеть: поле дня (зерно, общее правило), новые хозяева и находки из готовых
  кирпичиков (видимость, сердца, флаги, движение мин) — каждое правило проходит прогон решателя
  на 500 полях до попадания в игру.

## Этапы

1. MVP: Сапёр, три слоя только с обычными минами, открытие / флаг / открытие вокруг числа,
   сердца, первое нажатие безопасно, сохранение каждого хода.
2. Решатель и генерация без угадывания в Web Worker с запасом полей.
3. Находки (10 инструментов и талисманов), тайники, лавка.
4. Двойные, бродячие, часовые мины и глухие клетки — с поддержкой в решателе.
5. Хозяева, сапёры, мастерская, глубины, «Чистый сапёр».
6. Поле дня, контент от модели, связки с жизнью.

## Как проверить

- Генератор: 10 000 полей каждого размера — 100% разгадываются решателем с учётом подсказок
  земли, доля подсказок < 1%, 95-й процентиль генерации < 80 мс на Fold5.
- Симулятор: бот-решатель с ошибкой человека (`missRate` 2% нажатий не туда). Цели доли побед:
  пустая мастерская — 25%; середина — 60%; максимум, глубина 0 — 90%; глубина 12 — 20%.
- На телефоне: попадание по клетке на внешнем экране без промаха; прокрутка не открывает клеток;
  force-stop после хода — тот же ход восстановлен.

## Открытые вопросы

- Сердца (как описано) или классическая смерть от первой мины с одним щитом?
- Нужны ли бродячие мины вообще — они самые спорные для «чистой логики»?
- Долгое нажатие — флаг, или по умолчанию переключатель режима?
