Маскот

Персонаж приложения. Его можно перекрасить, заменить любым другим или убрать совсем — приложение работает и без него.

Будет ли маскот кнопкой чата и каким будет значок приложения, выбирается в «Настройки → Вид».

Окрас

Обычно маскот носит цвета темы. Свой окрас остаётся при любой теме.

Свой персонаж

Любая картинка вместо маскота — или попросите в чате: «нарисуй вместо аксолотля лису», «перекрась маскота в зелёный», «убери маскота».
